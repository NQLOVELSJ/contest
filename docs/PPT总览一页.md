# 双足导盲轮足机器人 — 技术总览（一页PPT用）

> 双芯片：OpenMV H7+ (Cortex-M7 480MHz + 32MB SDRAM) → 感知/规划 | ESP32-S3 (Xtensa LX7 240MHz 双核) → 控制/交互/安全 | UART 921600bps 单向二进制帧 (11B)

## 硬件拓扑
- **OV5640 固定摄像头**（60° FOV, FOMO 3类检测, 输出障碍物方位角 θ）
- **Pan 舵机载超声波**（舵机 0~140°扇区, 超声 ±0.5cm 温补测距, 球坐标 → (x,y)）
- **BLDC 轮毂 ×2**（FOC 速度模式, 差速零半径转向） + **MG996R 舵机 ×4**（5连杆并联腿机构）
- **MPU6050**（互补滤波姿态估计, >45° 摔倒断电） + **力传感器手柄**（导纳力控） + **离线 ASR/TTS**

## 感知层（OpenMV）
- **FOMO 目标检测**：TFLite Micro, 240×240 输入, chair/column/hands 3类, ~30ms/帧, conf≥0.5
- **畸变校正**：径向 k₁/k₂ + 切向 p₁/p₂, 亚像素精炼标定重投影 <0.15px, 仅校检测框中心, 残差 <0.1°
- **视觉制导超声测距**：固定摄像头 → 像素→方位角 θ → 舵机超声对准 → 球坐标(r,θ)→(x,y), 横向 ±7cm 前向 ±2cm@1m (95%)
- **双通道冗余决策**：正常态视觉 AND 超声(r<100cm) 激活势场; 安全态超声 OR (r<30cm) 触发紧急转向; 仅有视觉视为虚警不避障

## 规划层（OpenMV）
- **A* 全局路径规划**：100×100 栅格(10×10m), 8方向, 欧几里得启发式, 20-50ms/次, 10Hz, LOOKAHEAD=3-5格
- **人工势场局部避障**：A*引力方向 + 球坐标(r,θ)斥力 → 合力→转向偏差→左右轮避障因子; 双轮足零半径转向支持"先转后走"

## 控制层（ESP32-S3）
- **串级 PID**：外环速度PID(PIDController含Tustin积分+抗饱和+输出斜率限制) → 内环直立PD(无I, Kp对抗重力+Kd阻尼) → 转向P → 轮速分配; 频率50-200Hz
- **腿高自适应参数调度**：PID_Stb.Kp/PID_VEL.P 随腿高70-130mm 按二次函数平滑插值; 直立PD Kp随质心高度单调增大 (倒立摆 m·g·L·sinθ)
- **5连杆并联逆运动学**：闭链拆为双2连杆开链解析解 → 4舵机角度; L1=L4=60 L2=L3=100 L5=40mm; x∈[-30,30] y∈[70,130]mm; 并联方案承载比高、舵机负载低
- **BLDC FOC + 质心自校准**：FOC速度模式 Serial2 UART双向; `centerAngleOffset` 每200ms按-sgn(speedAvg)×0.8修正, 1-2秒收敛零速直立

## 交互层（ESP32-S3）
- **导纳控制力控随行**：多维力传感器→F_push/D_viscous(5.0)→目标速度; 有效力[0.5N,20N]; >20N急停
- **离线AI语音**：ESP-SR 20命令词(运动/导航/查询), 安静>92%; TTS预合成I2S DAC播报障碍/电量/确认
- **WiFi远程监控**：热点 SSID:MyRobot, WebSocket 1Hz JSON广播 (距离/状态/角度)

## 安全层（ESP32-S3）
- **通信看门狗**：>300ms未收帧→降速保持; >1000ms→电机归零舵机锁位
- **IMU摔倒**：pitch>45°→电机断电舵机关闭
- **力传感器急停**：>20N推力→反向100%扭矩200ms→归零; 腿高硬限位[70,130]mm
