# 视觉制导 + 舵机超声的障碍物三维定位：原理、标定与误差分析

## 一、问题定义

单目摄像头能给出高精度的角度信息——"障碍物在我的左前方 17°"。但单目无法直接测距。超声波能精确测距——"前方 85cm 有东西"——但无法分辨方向（波束锥角约 12°，相当于透过一根锥管往外看，知道有东西但不知道在锥管里的哪个位置）。

本方案的设计是：**固定摄像头负责搜索障碍物并确定方位角，舵机载着超声波旋转到该方向对准测距**。摄像头回答"往哪儿量"，超声波回答"有多远"。

---

## 二、传感器分工

| 指标 | 固定摄像头 OV5640 | 旋转超声波 (舵机载) |
|------|------------------|-------------------|
| 角度精度 | ~0.25°/px（校正后） | — |
| 角度覆盖 | 60°（瞬时 FOV，固定前向） | 随舵机，约 140° 扇区 |
| 测距精度 | — | ±0.5cm（温补） |
| 测距范围 | — | 2-400cm |
| 语义信息 | ✅（FOMO 模型，三分类） | ❌ |

摄像头固定不动，始终保持 60° 前向视野。一旦检测到障碍物，根据像素坐标算出目标方向角，指令舵机把超声波转过去对准，然后超声波测距。两个传感器各司其职。

## 三、硬件安装与坐标系

### 3.1 安装结构

```
          ┌──────────┐
          │ 摄像头   │ ← 固定在机器人正面，不可旋转
          │ OV5640   │
          └──────────┘

          ┌───────────────┐
          │  Pan 舵机     │ ← 水平旋转轴
          │  (Servo1)     │
          └───────┬───────┘
                  │
          ┌───────┴───────┐
          │  超声波模块   │ ← 刚性连接在舵机上
          │  HC-SR04      │     随舵机旋转
          └───────────────┘
```

### 3.2 坐标系约定

```
机器人坐标系（右手系）：
  X 轴：机器人右侧（横向）
  Y 轴：机器人正前方
  Z 轴：垂直向上
  原点：超声波发射面中心在地面的投影

球坐标 (r, θ)：
  r：超声波实测距离（经声速补偿）
  θ：超声波指向角度 = pan 舵机当前角度
     (θ=0° 为正前方，左正右负)
```

## 四、完整变换管线

一次障碍物定位经过以下步骤：

```
① FOMO 检测 → 障碍物像素坐标 (cx, cy)
         │
         ▼
② 畸变校正（仅校正检测框中心坐标, 一个浮点表达式）
         │
         ▼
③ 像素横坐标 → 障碍物方位角 θ_target
         │
         ▼
④ Pan 舵机旋转超声波至 θ_target 方向
         │
         ▼
⑤ 超声波发射 → 接收回波 → 温补距离 r
         │
         ▼
⑥ 球坐标 (r, θ_target) → 笛卡尔 (x, y)
```

步骤 ①-③ 由 OpenMV 完成，步骤 ④-⑤ 由舵机 + 超声波（OpenMV 直连 GPIO）完成，步骤 ⑥ 由 OpenMV 完成，结果以避障因子形式发给 ESP32。

---

### 4.1 像素坐标 → 归一化图像坐标

```
u_n = (u - cx) / fx
v_n = (v - cy) / fy

cx ≈ cy ≈ 120
fx ≈ fy ≈ 150（60° FOV, 240px → fx = 120 / tan30°）
```

### 4.2 径向畸变校正

OV5640 桶形畸变由一阶和二阶径向系数描述。切向畸变极小（<0.001），忽略。

```
r² = u_n² + v_n²
u_c = u_n · (1 + k₁·r² + k₂·r⁴)
v_c = v_n · (1 + k₁·r² + k₂·r⁴)
```

标定流程：20-30 张棋盘格（三脚架拍摄，固定曝光，15° 多姿态）→ `findChessboardCorners()` → **`cornerSubPix()` 亚像素精炼**（终止条件 EPS=0.001, 迭代 30 次）→ `calibrateCamera()` 输出 K 和 distCoeffs（含 k₁,k₂,k₃,p₁,p₂）。亚像素精炼将棋盘格角点定位精度从 ~0.5px 提至 <0.1px，重投影误差从约 0.3px 降至 **<0.15px**，即畸变校正角度残差 <0.04°。即使计入切向畸变残余和标定板平面度误差，总体上畸变校正对最终角度的贡献 <0.1°。

### 4.3 像素 → 超声波目标方向角

```
θ_pixel = (u_c - 120) / 120 × 30°       (摄像头内部偏角)
θ_target = θ_pixel                       (摄像头固定，绝对方向角 = 内部偏角)
```

即 OpenMV 检测到的障碍物在 u_c=160 时，其绝对方向角 θ_target = (160-120)/120×30° = +10°（右侧 10°）。

### 4.4 舵机控制

Pan 舵机（OpenMV 控制，Servo 1）将超声波旋转到 θ_target：

```python
PAN_CENTER = 140            # 舵机正前方的角度值
servo_angle = PAN_CENTER + (u_c - 120) / 120 * 30
pan_servo.angle(180 - servo_angle)   # 反向安装，角度翻转
```

MG996R 舵机定位精度约 ±1°，作为超声波指向精度的主要限制因素。

### 4.5 超声波测距

OpenMV 直接通过 GPIO 控制超声波的 TRIG/ECHO：

```
1. TRIG = 1 → 延时 20μs → TRIG = 0
2. time_pulse_us(ECHO, 1, timeout=6000) → 回波脉宽 Δt
3. v_sound = 331.3 + 0.606·T        (T: °C, 温补芯片提供)
4. r = v_sound · Δt / 2
```

OpenMV 的 time_pulse_us() 定时精度 ±2μs，距离分辨率约 0.034cm，远优于超声波的物理限制（表面反射不规则性等，约 ±0.5cm）。

### 4.6 球坐标 → 笛卡尔坐标

```
x = r · sin(θ_target)       横向偏移 (cm), 右侧为正
y = r · cos(θ_target)       前向距离 (cm)
```

其中 θ_target 取舵机旋转后的实际角度，而非目标角度——用 `get_current_pan_angle()` 读取舵机当前角度反馈值，消除舵机角度跟踪误差对坐标解算的影响。

## 五、误差分析

### 5.1 误差源

| 环节 | 误差源 | 量级 |
|------|-------|------|
| ① | FOMO 特征图量化（8× 下采样 → 缩放回映射） | ±4px → ±1.0° |
| ② | 畸变校正残差（含径向+切向） | <0.1°（亚像素精炼后） |
| ③ | 舵机角度定位误差 | ±1.0° |
| ④ | 超声波测距误差（温补后） | ±0.5cm |
| ⑤ | 超声波安装机械偏角（可校准） | ±1.5° |

### 5.2 合成效果

以上五个误差源中，距离误差（±0.5cm）对最终坐标的影响极小。角度误差合成约 2.1°，在 1m 距离处通过 r·sin(θ) 放大为约 **±7cm 的横向不确定度**（95% 置信）。前向不确定度仅约 ±2cm，由超声波测距精度主导。

畸变校正残差经过亚像素标定精炼后已压缩到 <0.1°，不再是误差预算中的显著项。舵机角度误差（±1.0°）和安装机械偏角（±1.5°）合起来贡献了角度方差的 80% 以上——想进一步缩小横向误差，方向在于机械校准而非算法优化。

### 5.3 工程意义

±7cm 的横向误差直接决定了避障安全间隙——当前系统将最小绕行间隙设为 15-20cm（约 2σ），保证了 95% 以上的安全裕度。

## 六、舵机旋转超声 vs 固定超声的对比

| 维度 | 超声随舵机旋转（本方案） | 超声固定正前向 |
|------|----------------------|-------------|
| 对不同方向障碍物的距离精度 | ✅ 能测量任意方位障碍物的距离 | ❌ 仅正前方 ±6° 波束内 |
| 对正前方障碍物的持续监测 | ⚠️ 旋转到侧方时正前方短暂无覆盖 | ✅ 始终监测 |
| 传感器选择 | 只需 1 个 | 只需 1 个（或需多个组成环形） |
| 系统复杂性 | 略高（超声信号线随舵机动） | 低 |
| 导盲场景适配 | ✅ 对准最危险障碍物测距 | ⚠️ 侧方障碍物无法测距 |

选择舵机旋转超声的核心原因是——**对检测到的任意方位障碍物，都能通过舵机对准后获得其精确距离**。代价是：当舵机转到侧方对准侧方障碍物时，正前方有约 100ms 的超声覆盖空白（一帧周期）。在步行速度下不构成问题。

---

## 七、动态障碍物

本方案对动态障碍物的处理和静态障碍物无本质区别——第一帧摄像头检测到障碍物方向 θ，舵机对准，超声测距 r，球坐标定位。下一帧如果障碍物移动了 10-20cm，摄像头重新检测到新方向 θ'，舵机再转过去对准，超声重测 r'。整个过程相当于把移动障碍物当作"每一帧出现在不同位置的新静态障碍物"来处理。

```
条件: 帧间位移 < 超声波束覆盖范围
设定: 行人 ≤1.0m/s, 帧周期 100ms, 帧间位移 10cm
      超声在 1m 处波束覆盖直径 ≈ 20cm
      → 10cm < 20cm → 满足条件
```

---

## 八、总结

三维定位管线：**固定摄像头给方向 θ，舵机把超声波转过去给距离 r，球坐标合成 (x, y, z)。**

三个设计原则：

1. **摄像头固定** → 全程 60° 无盲区监视，不会因为舵机转动错过障碍物
2. **超声波旋转** → 对其指向的任何障碍物给出精确距离（±0.5cm），突破固定超声的波束锥限制
3. **舵机角度是精度瓶颈**（±1°），但也足够支撑避障所需的安全间隙
