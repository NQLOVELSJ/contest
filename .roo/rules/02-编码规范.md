# 02-编码规范

## 命名规范

### 1. 变量命名
- **全局变量**: 使用 `g_` 前缀 + snake_case
  ```cpp
  float g_robot_height = 20.0f;
  uint32_t g_last_update_time = 0;
  ```

- **局部变量**: 使用 snake_case
  ```cpp
  float current_angle = 0.0f;
  uint16_t servo_position = 1500;
  ```

- **常量**: 使用 UPPER_CASE
  ```cpp
  #define MAX_SERVO_ANGLE 180
  const float PI = 3.1415926f;
  ```

### 2. 函数命名
- 使用 snake_case，动词开头
  ```cpp
  void get_imu_data();
  float calculate_pid_output(float error);
  void set_servo_angle(uint16_t angle);
  ```

### 3. 结构体命名
- 使用 snake_case，描述性名称
  ```cpp
  typedef struct {
      float pitch;
      float roll;
      float yaw;
  } imu_data_t;
  ```

## 代码风格

### 1. 缩进和空格
- 使用 2 个空格缩进
- 操作符前后加空格
  ```cpp
  float angle = (current + target) / 2.0f;
  if (angle > MAX_ANGLE) {
      angle = MAX_ANGLE;
  }
  ```

### 2. 大括号风格
- K&R 风格，左大括号不换行
  ```cpp
  void control_loop() {
      if (condition) {
          // code
      } else {
          // code
      }
  }
  ```

### 3. 指针和引用
- 指针符号 `*` 靠近类型
- 引用符号 `&` 靠近类型
  ```cpp
  imu_data_t* imu_ptr = &imu_data;
  float& angle_ref = current_angle;
  ```

## 注释规范

### 1. 文件头注释 (Doxygen 风格)
```cpp
/**
 * @file main.cpp
 * @brief 双轮足机器人主控制系统
 * @author Your Name
 * @date 2024-01-01
 * @version 1.0
 */
```

### 2. 函数注释
```cpp
/**
 * @brief 计算机器人逆运动学
 * 
 * 根据目标位置计算各关节角度，实现机器人腿部运动控制
 * 
 * @param target_x 目标X坐标
 * @param target_y 目标Y坐标  
 * @param target_z 目标Z坐标
 * @return bool 计算是否成功
 */
bool calculate_inverse_kinematics(float target_x, float target_y, float target_z);
```

### 3. 行内注释
- 复杂算法或关键逻辑需要行内注释
- 注释使用英文，简洁明了
  ```cpp
  // Apply low-pass filter to smooth IMU data
  filtered_angle = alpha * raw_angle + (1 - alpha) * filtered_angle;
  ```

## 错误处理

### 1. 返回值检查
```cpp
if (!imu_sensor.begin()) {
    Serial.println("IMU initialization failed!");
    return false;
}
```

### 2. 边界检查
```cpp
float safe_angle = _constrain(raw_angle, MIN_ANGLE, MAX_ANGLE);
```

## 性能优化

### 1. 避免浮点运算
- 在中断服务程序中使用整数运算
- 必要时使用定点数

### 2. 内存管理
- 避免动态内存分配
- 使用静态数组或预分配内存

### 3. 中断安全
- 中断服务程序尽量简短
- 使用 volatile 关键字保护共享变量
