# 01-项目概述

## 项目背景
本项目是一个基于 ESP32-S3 的双轮足机器人控制系统，采用 PlatformIO 开发环境。项目主要实现机器人的运动控制、姿态感知、遥控操作和自主导航功能。

## 核心模块

### 1. 主控制系统 (main.cpp)
- **功能**: 系统主循环，协调所有模块运行
- **关键组件**: 
  - 遥控器数据接收 (SBUS)
  - IMU 姿态感知 (MPU6050)
  - 舵机控制 (SF_Servo)
  - 电机控制 (SF_BLDC)
  - 超声波避障 (HC-SR04)
  - OpenMV 视觉处理

### 2. 机器人数据结构 (bipedal_data.h)
- **功能**: 定义机器人状态和控制参数的数据结构
- **关键结构体**:
  - `robotposeparam`: 机器人姿态参数 (俯仰角、横滚角、偏航角等)
  - `robotmotionparam`: 机器人运动参数
  - `robotmode`: 机器人工作模式
  - `motorstatus`: 电机状态
  - `controlparam`: 控制目标参数

### 3. 运动控制算法
- **逆运动学计算**: `inverseKinematics()`
- **腿部控制**: `legControl()`
- **重心自校准**: `selfCaliCentroid()`
- **高级势场导航**: `advancedPotentialFieldNavigation()`

### 4. 传感器模块
- **IMU 传感器**: MPU6050，提供姿态数据
- **遥控器**: SBUS 协议，6通道控制
- **超声波**: HC-SR04，障碍物检测
- **摄像头**: OpenMV，视觉识别

## 主要文件及其作用

| 文件名 | 作用 | 重要性 |
|--------|------|--------|
| `src/main.cpp` | 主程序文件，包含系统主循环和核心逻辑 | ★★★★★ |
| `src/bipedal_data.h` | 数据结构定义文件，包含所有机器人参数 | ★★★★★ |
| `src/index_html.h` | Web 控制界面 HTML 代码 | ★★★★☆ |
| `platformio.ini` | PlatformIO 项目配置文件 | ★★★★☆ |

## 硬件平台
- **主控芯片**: ESP32-S3
- **传感器**: MPU6050 (IMU)
- **执行器**: 舵机 + BLDC 电机
- **通信**: SBUS 遥控器、WiFi、蓝牙
- **电源**: 锂电池供电

## 开发环境
- **IDE**: PlatformIO (基于 VS Code)
- **框架**: Arduino Framework
- **编程语言**: C++
- **目标板**: esp32-s3-devkitc-1
